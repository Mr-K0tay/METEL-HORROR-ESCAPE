# K0TAYHACK — чит для METEL HORROR ESCAPE

**Автор:** Mr_K0tay
**Версия чита:** 0.26.1 (сборка плагина 1.12) · **Игра:** 1.01 (Unity 2022.3.37f1, Mono) · **Загрузчик:** BepInEx 5.4.23.2

---

## 🎮 Возможности

Меню чита открывается на **TAB** (или INSERT / ~) и имеет 4 вкладки.

### Вкладка MAIN
| Функция | Клавиша | Описание |
|---|---|---|
| **GODMODE** | `F1` | Полная неуязвимость: удары маньяка, электричество, газ, пермасмерти — всё блокируется. Капканы безвредны: не захлопываются, не удерживают игрока, маньяк не приходит. Остальные шумы (шаги, стекло) работают как обычно |
| **NOCLIP** | `F2` | Полёт сквозь стены |
| **FLY** | `F3` | Полёт с коллизиями (WASD + SPACE вверх / CTRL вниз, SHIFT — ×2) |
| **MOVE OBJECTS** | `F4` | Захват и перемещение любых объектов прицелом |

Плюс: слайдер скорости полёта (2–60), 6 цветовых тем, водяной знак вкл/выкл, переназначение клавиши меню.

### Вкладка ПРЕДМЕТЫ
- Вкладки всех глав: АЛАН / ЭМИЛИИ / ЮДЖИН / АДЕЛЬ (+ автоматически найденные уровни); текущая глава подчёркнута красным
- **СПИСОК ГЛАВЫ** — канонические предметы главы, кнопка «ДАТЬ» у каждого (красная строка = предмета в этой главе нет)
- **ДРУГИЕ НАЙДЕННЫЕ [N]** — все прочие предметы, подгруженные сценой
- **X ОЧИСТИТЬ ИНВЕНТАРЬ** — полная очистка с отчётом
- Предметы ищутся умно: кириллица/латиница/ID — просто жми «ДАТЬ»

### Вкладка ОБЪЕКТЫ
- Статус захвата, кнопки **ЗАХВАТИТЬ / ОТПУСТИТЬ** (рейкаст 10 м от прицела)
- Шаг перемещения 0.05–3 м
- Крестовина ↑ ← ↓ → относительно взгляда + высота ▲ ▼
- Поворот объекта на 45° / 90° / 180° / 240° / 360°

### Вкладка INFO
Информация о версиях, ссылки автора, шпаргалка горячих клавиш.

## ⌨️ Горячие клавиши
```
TAB / INSERT / ~   открыть меню (клавиша меняется в настройках)
F1                 godmode
F2                 noclip
F3                 fly
F4                 move objects
WASD + SPACE/CTRL  полёт (SHIFT — ускорение ×2)
ESC                отмена переназначения клавиши
```
При открытом меню камера замирает — можно спокойно настраивать.

## 📦 Установка
1. Запусти **K0tayHack_Setup.exe**
2. Установщик сам найдёт папку игры (через Steam или типичные пути); если не нашёл — кнопка «Обзор...», нужна папка с `Metel.exe`
3. Нажми «Установить» → готово, можно сразу запустить игру

Что попадает в папку игры:
```
winhttp.dll            загрузчик (doorstop)
doorstop_config.ini    конфиг загрузчика
BepInEx\               ядро модов + K0tayHack_v12.dll в plugins
MonoBleedingEdge\      штатный рантайм игры (страховка, если отсутствует/сломан)
DelK_Hack.exe          деинсталлятор
```

Тихая установка (без окна): `K0tayHack_Setup.exe --install-to "C:\путь\к игре"`

---

## 🗑️ Удаление
Запусти **DelK_Hack.exe** в папке игры:
- закрой игру перед удалением — деинсталлятор откажется работать при запущенном Metel
- удаляет чит, BepInEx и MonoBleedingEdge, затем самоудаляется
- если стоят другие моды (чужие файлы в `plugins`/`patchers`) — удалит только чит

---

## ⚠️ Важно
- Поддерживается только **Mono-версия** игры. **Steam-версия не поддерживается**
- Некоторые антивирусы ругаются на `winhttp.dll` (стандартный способ загрузки модов через Unity Doorstop) — добавь папку игры в исключения
- Если после чистки вручную игра перестала запускаться с ошибкой про `mono-2.0-bdwgc.dll` — переустанови через установщик: он вернёт `MonoBleedingEdge`
